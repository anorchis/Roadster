# 로드스터 타고 포항 하늘 날기 🚗✈️

2026년 10월 공개된 **신형 테슬라 로드스터**(SpaceX 콜드가스 스러스터 탑재)를 타고 **포항시** 위를 날면서
비행기의 세 가지 회전 **롤(Roll) · 피치(Pitch) · 요(Yaw)** 를 배우는 3D 비행 시뮬레이션 게임입니다.

## 실행 방법

설치할 것이 없습니다. `index.html` 을 크롬/엣지/사파리로 열면 바로 실행됩니다.
(three.js 라이브러리가 `lib/` 폴더에 들어 있어 인터넷 없이도 동작합니다.)

## 조작법

| 회전 | + 방향 | − 방향 | 뜻 |
|---|---|---|---|
| **롤** (빨강) | `D` / `→` 오른쪽으로 기울기 | `A` / `←` 왼쪽으로 기울기 | 앞뒤 축을 중심으로 좌우로 기울이기 |
| **피치** (초록) | `W` / `↑` 기수(앞코) 올리기 | `S` / `↓` 기수 내리기 | 좌우 축을 중심으로 앞코를 들고 숙이기 |
| **요** (파랑) | `E` 기수를 오른쪽으로 | `Q` 기수를 왼쪽으로 | 위아래 축을 중심으로 방향 돌리기 |

- `R` / `F` : 스로틀(속도) 올리기 / 내리기
- `Space` : SpaceX 스러스터 부스트
- `C` : 카메라 바꾸기 (추적 / 조종석 뒤 / 옆에서 / 위에서)
- `G` : 회전축 화살표 켜기·끄기, `N` : 다음 미션, `P` : 일시정지, `M` : 소리, `H` : 도움말
- 태블릿에서는 화면 아래 롤·피치·요 버튼을 직접 눌러 조종할 수 있습니다.

### 무엇을 눌렀는지 보이게
- 화면 아래 **롤·피치·요 표시판**에서 누른 쪽(+/−) 버튼이 불이 들어오고, 뒤/옆/위에서 본 차의 모습과 각도가 실시간으로 바뀝니다.
- 가운데에 **"지금 누른 것: 롤 + (오른쪽으로 기울기)"** 처럼 글자로도 표시됩니다.
- 차 주위에 해당 **회전축과 회전 방향 화살표**(빨강/초록/파랑)가 나타납니다.
- 능동형 리어윙이 비행기 조종면(에일러론·엘리베이터·러더)처럼 움직이고, 작은 **자세 제어 가스 분사**가 보입니다.

## 미션

1. **롤 배우기** – 오른쪽/왼쪽으로 45° 이상 기울여 2초 버티기
2. **피치 배우기** – 앞코를 들어 420m까지 올라갔다가 150m 아래로 내려오기
3. **요 배우기** – 기울이지 않고(롤 15° 이내) 요만으로 오른쪽·왼쪽 90° 돌기
4. **한 바퀴 롤** – 롤 키를 계속 눌러 360° 회전
5. **공중제비(루프)** – 피치로 360° 회전
6. **스페이스워크 선회 비행** – 롤로 기울이고 피치로 당겨 환호공원 스페이스워크 주위 한 바퀴
7. **형산강 고리 통과** – 형산강을 따라 놓인 고리 7개 통과
8. **칼날 비행: 포스코 게이트** – 롤 60° 이상으로 차를 옆으로 세워 좁은 틈 통과
9. **호미곶 상생의 손까지** – 영일만을 가로질러 상생의 손까지 고리 5개 통과

미션을 모두 마치면 자유 비행을 할 수 있습니다. 시작 화면에서 원하는 미션을 골라 시작할 수도 있습니다.

### 🚗 착지하면 자동차로 달리기
로드스터는 자동차라서 **바퀴가 아래를 향한 채 땅에 내려앉으면 착지**해서 땅 위를 달립니다.
- 핸들: `A`/`D` 또는 `Q`/`E` — 자동차가 방향을 바꾸는 것도 **요(Yaw)** 라서 요 표시판에 불이 들어와요
- `R` 가속, `F` 감속, `S` 브레이크, `Space` 부스트
- 120km/h 이상에서 `W`(피치 +)를 누르면 다시 **이륙**

**건물·명소에 부딪히거나, 바다·강에 빠지거나, 뒤집히거나 거꾸로 꽂히듯 땅에 떨어지면 "쾅!" 하고 현재 미션의 처음 위치로 초기화됩니다.**

## 포항 지도

실제 위도·경도를 바탕으로 영일만 해안선, 형산강, 시가지(중앙동·죽도, 두호, 양덕, 이동, 오천, 구룡포 등),
포스코 제철소, 포항공항, 포항역, 스페이스워크(환호공원), 영일대 해상누각, 호미곶 상생의 손과 등대를 배치했습니다.
비행 시간이 너무 길지 않도록 **수평 거리는 실제의 0.35배**로 줄였습니다.

## 로드스터 모델에 대해

공식 치수가 아직 발표되지 않아, 공개된 디자인 특징을 바탕으로 만든 **근사 모델**입니다.
낮고 넓은 쐐기형 차체, Ano White 도장, 골드 틴트 유리, 숨은 헤드라이트(얇은 LED 라인), 차폭 전체 테일라이트,
능동형 리어윙, 뒤쪽 가로 배열 스러스터 노즐 4개, 2인승. 길이 약 4.3m / 폭 약 2.0m / 높이 약 1.15m로 가정했습니다.

## 파일 구성

- `index.html`, `css/style.css` – 화면과 표시판
- `js/geo.js` – 포항 지형(해안선·강·시가지·명소 좌표)
- `js/world.js` – 하늘·지형·바다·건물·포스코·명소·충돌체
- `js/roadster.js` – 로드스터 3D 모델, 회전축 화살표, 리어윙/스러스터 애니메이션
- `js/missions.js` – 롤·피치·요 미션
- `js/main.js` – 비행 물리, 입력, 카메라, 충돌, HUD
- `js/audio.js` – 효과음
- `lib/three.min.js` – three.js r149 (MIT 라이선스, `lib/three.LICENSE`)
